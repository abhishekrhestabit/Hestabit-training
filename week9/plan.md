# AI Mastery Study Plan: 2024-2025 Edition

**Objective:** Transition from AI enthusiast to practitioner by mastering the current industry shift toward efficiency, multimodal LLMs, and agentic workflows.

## Phase 1: Foundations (Weeks 1-3)
*Goal: Understand the mathematical and structural logic behind modern AI.*
* **Linear Algebra & Calculus Refresher:** Focus on vectors, matrices, and gradients to grasp how backpropagation works.
* **Python for AI:** Master data manipulation and deep learning frameworks (`NumPy`, `Pandas`, `PyTorch`).
* **Core Concepts:** Deconstruct the Transformer architecture ("Attention is All You Need"), understand tokenization, and distinguish between pre-training and fine-tuning.

## Phase 2: Modern LLM Ecosystem (Weeks 4-6)
*Goal: Adapt to the shift from generic prompting to model optimization.*
* **SLM Implementation:** Experiment with smaller, efficient models (Microsoft Phi-3, Google Gemma) and deploy them locally using `Ollama` or `LM Studio`.
* **Context Management:** Master RAG (Retrieval-Augmented Generation) architectures to leverage large context windows effectively.
* **Orchestration Tools:** Use `LangChain` or `LlamaIndex` to connect models to external data sources and APIs.

## Phase 3: Specialization & Agentic AI (Weeks 7-9)
*Goal: Move from static "Chat" to autonomous "Action".*
* **Agentic Workflows:** Design agents capable of tool-use (web searching, file system interaction, and calculation).
* **Parameter-Efficient Fine-Tuning (PEFT):** Practice techniques like LoRA (Low-Rank Adaptation) to customize models for specific, niche tasks.
* **Multimodal AI:** Integrate vision, audio, and text processing into unified workflows.

## Phase 4: Capstone Project (Weeks 10-12)
*Goal: Build a deployable, privacy-first product.*
* **The Project:** Build a local-first application using an SLM that processes a private knowledge base (e.g., personal documents) without cloud reliance.
* **Evaluation:** Implement metrics like RAGAS to scientifically measure the accuracy and performance of your RAG pipeline.
